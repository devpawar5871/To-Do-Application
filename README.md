# 📝 Flutter To-Do App

A simple and beginner-friendly To-Do application built using Flutter.  
This app allows users to add, update, edit, and delete daily tasks easily.

## ▶️ Getting Started

### Prerequisites

- Flutter SDK
- Android Studio or VS Code
- Emulator or Physical Device

---

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/flutter-todo-app.git
```

### Open Project

```bash
cd flutter-todo-app
```

### Install Packages

```bash
flutter pub get
```

### Run App

```bash
flutter run
```
